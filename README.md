# PrepQuest

PrepQuest is a Flutter Android MVP for competitive exam preparation, built for Indian aspirants preparing for UPSC, JPSC, and RBI Grade B.

## Features

- Home dashboard
- Exam selection
- Syllabus tracker
- Daily study tracker
- Progress dashboard
- Settings
- Local offline persistence with Hive

`C:\Users\Xenoforce\Documents\appjpsc\prepquest`

## Run

1. Install Flutter stable and Android Studio.
2. Open the project root in Android Studio or VS Code.
3. Run:

```bash
flutter pub get
flutter run
```

## Notes

- Data is stored locally on device only.
- No login system is included in MVP.
- The Android project files were prepared manually in this workspace, so local Flutter/Gradle tooling should be allowed to regenerate any machine-specific files during first run.
